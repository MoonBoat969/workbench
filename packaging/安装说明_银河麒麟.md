# 专属工作台 v1.4.2 — 银河麒麟（飞腾 arm64）安装说明

本包**仅包含 arm64（aarch64）依赖**，适用于银河麒麟桌面 V10 + 飞腾 D2000 等 arm64 机器。
Windows 请使用对应的 Windows64位 包，二者不可混用。

## 前置条件

- 系统自带的 `python3`（3.7 / 3.8 / 3.10 之一）
- `python3-tkinter`（麒麟桌面版一般已预装；缺了界面无法启动）

## 直接运行（源码方式）

```bash
cd 本目录
bash install_kylin.sh      # 安装离线依赖到 pylibs/（自动识别 arm64 与 python 版本）
bash start.sh             # 启动桌面版
```

## 制作并安装 deb（推荐）

```bash
bash install_kylin.sh
bash build_kylin.sh        # PyInstaller 打包绿色版（含依赖自检）
bash build_deb.sh          # 生成 dist/专属工作台_1.4.2_arm64.deb
sudo dpkg -i dist/专属工作台_1.4.2_arm64.deb
```

安装后程序位于 `/opt/专属工作台`，带桌面图标与开机自启，Web 服务随开机启动。
卸载：`sudo dpkg -r zhuan-shu-gong-zuo-tai`

## 内网 Web 版

```bash
bash web/start.sh              # 默认 8000 端口
bash web/start.sh 9000 口令     # 指定端口与访问口令
```

浏览器访问 `http://本机IP:8000`；Web 与桌面版共用 `data/workbench.db`。

## 数据位置

- 源码运行：本目录下 `data/workbench.db`
- deb 安装：`/opt/专属工作台/data/workbench.db`
